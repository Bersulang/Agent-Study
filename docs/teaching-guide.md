# 教学与知识维护方式

## 你的学习起点

Python 按初学者讲解，Java Web 经验用于建立联系。不能因为你会 Java，就省略 Python 的运行方式、引用、数据结构、异常、模块和异步机制。

## 每课的固定结构

1. **业务场景**：用主项目中的具体问题解释为什么要学。
2. **学习目标**：本课结束后能完成什么，前置知识是什么。
3. **概念讲解**：定义、例子、Java 对照和区别。
4. **操作演示**：文件位置、完整命令和预期结果。
5. **代码解释**：执行顺序、数据变化和首次出现的语法。
6. **常见错误**：症状、原因、检查步骤和修复方式。
7. **独立练习**：与示例相关，但需要迁移，不照抄完整答案。
8. **验收与回顾**：检查解释、修改、排错和验证能力。

这套结构参考案例驱动和讲练结合的教学组织方式，讲义与代码独立编写。参考入口：[黑马 Python 入门课程介绍](https://yun.itheima.com/course/542.html)。不按该课程的天数安排，也不搬用原课程文字或代码。

## 代码怎样讲

- 新语法先用直白版本解释，再展示更简洁的写法。
- 不为了展示高级语法，在入门案例加入不必要的类、装饰器或抽象。
- 注释说明目的、输入、输出、关键状态和失败路径。
- 对复杂逻辑，讲义配执行过程；注释与代码共同维护。
- 所有代码文件，包括练习和答案，都有中文说明。
- 参考答案只作为对照，不代替你的独立实现。

## 怎样判断掌握

| 能力 | 需要的依据 |
| --- | --- |
| 能解释 | 用自己的话说明概念和执行过程 |
| 能修改 | 独立完成一个变化后的需求 |
| 能排错 | 根据命令、错误和状态定位问题 |
| 能验证 | 用运行结果或测试判断是否满足要求 |

能复制运行是起点。课程已经写好、示例已经通过验证，都不能证明你掌握了。

## 知识文档怎样维护

`knowledge.md` 是一个持续更新的知识手册，每个条目记录：概念、用途、最小例子、Java 对照、易错点、课程链接和来源。

课堂中的问题与作业反馈，确认原因后再写入相关条目。没有发生的错误不伪造为你的个人问题。全部56阶段资料已预先交付，但未学习或未验收的内容不能写成已掌握知识。

## 进度怎样维护

- 材料状态：未制作 / 已准备 / 已修订。
- 练习状态：未提交 / 已提交 / 待修改 / 已完成。
- 能力状态：待验收 / 部分掌握 / 已通过。

只有你提交操作结果、解释或代码，并经检查后，才更新能力状态。阶段尚未通过时，可以补充练习，不按日期强制推进。

## 技术与资料选择

初期优先 Python 标准库。模型 SDK、框架与协议在使用时核查官方文档与版本；每次新增依赖说明用途。开源项目用于理解机制与设计取舍，不将照搬项目作为学习目标。
