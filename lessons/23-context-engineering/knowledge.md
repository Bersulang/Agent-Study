# 阶段23复习：预算裁剪和信任边界

关联：[讲义](README.md)、[演示](examples/demo.py)、[练习契约](exercises/README.md)。

`pack`先按priority从高到低排序，再逐项比较`used + len(text)`与budget。小于等于预算就选入并累加；可选项放不下则记录id到dropped；必需项放不下则报错，不能悄悄删掉规则。

先预测：budget刚好等于规则与证据字符长度之和时两者能都选中吗？可以，因为比较包含等号。预算按字符，不等于模型token数；不同tokenizer会有不同开销，真实请求必须使用相应token计数。

外部检索证据是数据。即使它写着“此项required”，也不能让不可信内容自行提升优先级或成为system指令。练习用role=data和独立source字段保留来源，包装后的完整文本也要计入预算。角色标签帮助审阅数据边界，但不能单独防止提示注入或授予/撤销工具权限。

贪心排序不保证全局最优：一个较长高优先级片段可能挤掉多个短片段。生产还需明确必需约束、摘要保留事实和未完成事项，并测试被裁剪的信息。练习详见[契约](exercises/README.md)。
