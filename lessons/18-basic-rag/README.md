# 阶段 18：带引用的基础RAG

## 使用场景

员工问如何报销，系统需要先找到政策，再给出可定位的证据。

主线项目是企业知识与工单协作助手。本阶段只增加一个可解释的能力边界，先验证机制，再讨论规模化。
运行演示不需要模型密钥，也不会请求真实业务系统。

## 学习目标

- 能手算查询词与文档词的交集分数并追踪排序。
- 能说明无证据为何拒答、citation为何必须来自同一个命中。
- 能区分本地词项演示、真实Embedding检索和答案质量评估。

## 概念：从词项重叠到带出处回答

真实集成关卡：学员独立验收通过机制练习后，使用真实Embedding模型或本地Embedding服务为小型真实资料建索引，保存模型/服务版本、向量维度、检索结果和可核查引用。缺少模型环境时可继续其他离线课程；机制验收需由学员单独完成，真实集成仍标记待验收。

本课演示不是embedding检索：它先把空格分隔的词转成集合，再计算精确重叠数。查询“报销 发票”与第一份资料相交两个词，所以该资料排在前面；“工资”与所有资料交集为空，必须拒答。

下面摘录或简化本课示例的关键步骤，需结合[完整源码](examples/demo.py)中的定义与上下文阅读；运行时使用下方演示命令。

```python
terms = set(query.split())
score = len(terms & set(doc["text"].split()))
if score > 0:
    scored.append((score, doc))
```

`set`去掉重复词，`&`取交集，`len`把交集大小变成简单分数。排序键`(-score, id)`让分数高的排前，并用id稳定处理平分。先预测：查询“报销 发票 发票”会比“报销 发票”高分吗？不会，集合会去重。

命中后，`answer`只摘录第一条命中文档的文字，并把同一条记录的`source`放入citations。这个绑定很重要：若答案引用了未参与检索的来源，引用看起来完整也不能支撑内容。没有hits时返回`no_evidence`和空引用，而不是退回第一篇文档。

反例：词面重叠不代表语义正确；“旅行报销”可能找不到写着“差旅报销”的资料。即使采用真实embedding，最高分也不保证证据充分。无答案资料、拒答阈值和引用支持仍需评估。真实Embedding集成单独记录模型/服务版本、维度、检索结果和引用证据；缺少环境时离线课程可继续。

## 执行过程与状态变化

1. 问题转为空格分隔的词项集合。
2. 文档词项求交集，过滤零分。
3. 排序选择证据，保持来源。
4. 命中则摘录；无命中返回no_evidence。

正常执行链是`query → terms → scored候选 → 排序 → hits[0] → answer与citation`。无匹配时在取`hits[0]`之前就返回拒答，因此不会发生空列表越界，也不会拿无关资料凑答案。入口只打印结果，检索和回答逻辑可单独调用测试。

## 逐行阅读与Python语法

读`scored.sort(key=lambda item: (-item[0], item[1]["id"]))`时，item是(score, doc)二元组；负号改变升序排序的方向，第二项保证结果稳定。`scored[:2]`只限制候选数量，不表示前两条一定够回答。引用来自命中对象本身，避免手工拼出不存在的来源。

## 对照源码的逐行解释

按examples/demo.py中的顺序阅读，下列关键表达式决定正常与失败路径。

| 表达式或位置 | 为什么这样写及状态变化 |
|---|---|
| `set(query.split())` | 空格分词后去重；重复输入“报销 报销”不额外加分。中文自然句子未分词时可能完全不匹配。 |
| `terms & set(doc["text"].split())` | 集合交集是精确词重叠，同义词旅行与差旅不会自动相近。 |
| `score > 0` | 零分资料不能进入证据，否则“工资”也会拿到报销政策。 |
| `(-item[0], item[1]["id"])` | 负分数让默认升序等价高分优先，再按id固定并列顺序。 |
| `scored[:2]` | 只返回前2个候选；top-k是数量限制，不是证据充分度证明。 |
| `citations` | 引用与实际使用的hits[0]绑定，不能从未检索资料中生成漂亮但虚假的出处。 |
| `工程问题` | 模型向量检索即使最高分仍可能没有答案。标注无答案集校准阈值，验证每个回答事实是否被引用支持。 |

## Java Web对照

Java可用Set.retainAll求词项交集，排序用Comparator；本课citation必须从命中文档对象读取，不能把引用当独立拼接字符串。

## 易错点与排错顺序

1. 文件路径错误：确认终端在项目根目录，先运行演示而不是练习骨架。
2. 把空结果当成功：查返回状态与来源，不能编造缺失字段或证据。
3. 在失败后继续修改：先验证再变更，给失败输入补行为测试。
4. 共享可变对象：调用前后打印输入，确认是否被无意修改。
5. 把模拟效果当生产质量：检查本页边界说明与真实接入目录。
6. 只看最终回答：保留查询、状态或执行轨迹，定位失败发生在哪一步。
