# 阶段 50 独立练习

1. 新增两个版本包，坏版本发布失败且旧版本保持活跃。
2. 启动任务后再发布新版本，证明旧任务版本不变。
3. 先在本地运行课程验证命令，再说明将来接入CI时哪些生产变更仍需人工审查；本课不要求新增流水线。

## 提交

提交练习代码；自动校验命令会保存运行结果。设计原因可在验收对话中说明。

## 验收

能解释为何Git提交不等于完整行为版本；演示拒绝坏发布与安全回滚；说明有副作用的数据迁移不能靠切版本恢复。

完成后查看 [参考答案](../solutions/solution.py)，不要预先复制。

## 自动校验接口

实现`solve(data)`，必填`active_version`和`candidate`；candidate含`version`、`quality`、`valid`。候选仅在`valid`为真且`quality`至少为0.9时发布，否则保留旧版本。可选`task_version`代表已运行任务版本；省略时采用发布后的活动版本。返回`active_version`、布尔值`released`和`task_version`。此自动检查不验证真实版本包完整性或回滚副作用。

自动校验只验证上述可重复的行为子集；涉及真实模型、服务、身份、部署或需要设计解释的部分，仍按本课集成任务独立验收。校验日志由统一命令自动保存，不要求手工粘贴命令输出。

从项目根目录运行：`.\.venv\Scripts\python.exe tools/check_exercise.py 50`。
