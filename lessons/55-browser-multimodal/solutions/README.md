# 浏览器与媒体练习参考

`solution.py`验证审批、重复提交、页面后置条件、空文件、超限和未知MIME。

这只是媒体元信息初筛，不能证明文件内容符合标签。真实接入分别使用受限解码器解析图像、wave检查PCM WAV、pypdf解析PDF、CSV解析器读取表格，并验证内容大小、页数/时长与资源消耗。客户端提供的MIME与扩展名都不是可信事实。

真实页面练习见 [Playwright脚本](../integrations/browser_demo.py) 和 [启动说明](../integrations/README.md)：fill标题、click提交后，断言status文本是DEMO-T-001，而不是只看点击成功。

本地模型练习按同目录图像/音频说明设置模型路径并运行，记录输入、识别文本、错误与人工核验。没有模型环境时明确写未执行，不用演示夹具替代真实识别结果。
