# 阶段24复习：可归属、获同意、可撤销的记忆

关联：[讲义](README.md)、[演示](examples/demo.py)、[练习契约](exercises/README.md)。

偏好只在用户与记忆键共同确定的位置保存：`(user, key)`。u1的language=中文不会被u2读到。`put`先检查consent，再存value/source/expires；未经同意时不得覆盖原值。

读取时，记录不存在或`now >= expires`都返回None。期限恰好到达时已过期。`forget`通过`pop(..., None)`执行幂等删除。若同一用户重新指定新值，简单字典会覆盖旧值；生产审计可能需要版本记录。

先预测：u1撤销语言偏好后，u2的同名偏好会怎样？不会受影响，因为复合键包含用户。练习修正接口需要返回旧值、新值和来源，但若consent为False必须先拒绝、保持Memory不变，也不能读取其他用户的旧值来拼审计结果。

Java里可用不可变复合键或(user,key)数据库唯一键表达同一隔离。当前实现只在内存中，重启后丢失；没有认证、持久化、备份删除或撤销传播保证。把聊天全文保存成长期记忆也超出这里定义的明确事实/偏好范围。
