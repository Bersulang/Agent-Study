# 阶段21独立练习

先关闭参考答案，只阅读本页与讲义。

## 业务要求

实现按租户和部门同时过滤的查询；缓存键必须包含tenant与department。给出两租户同词查询不会共享结果的验证。

## 实施约束

- 在practice.py中自行定义清晰的函数参数，不依赖调用顺序的隐藏全局变量。
- 保留来源、身份或任务标识中与本题有关的字段；异常不能伪装成成功。
- 只能使用标准库；写文件放临时目录或项目artifacts，不修改原始资料。
- 写中文注释解释边界判断原因，而不是逐个翻译变量名。

## 提交证据

从项目根目录执行 `python lessons/21-knowledge-permissions/exercises/practice.py`。

提交代码、三个输入输出记录（正常、边界、失败），以及为何失败应该被拒绝的说明。
输出不能只是一句完成提示，必须展示你实现的结果。

## 独立验收

1. 改变一条输入资料后，结果是否随业务规则改变？
2. 删除关键字段或减少预算时，是否有明确失败/部分结果？
3. 重复执行是否导致额外写入或状态污染？说明适用范围。
4. 能否用自己的话解释本课教学模拟与真实集成之间的差异？

完成后再运行 `python lessons/21-knowledge-permissions/solutions/solution.py` 对照设计，不以输出文本完全一致作为唯一标准。
材料已提供不等于能力已通过；验收必须由你的独立实现和解释支持。
