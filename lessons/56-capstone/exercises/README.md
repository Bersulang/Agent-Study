# 阶段 56 独立练习

本练习要扩展一个完整企业助手项目；`practice.py`仅是尚未完成的练习骨架，不是要求提交的全部成果。主项目阶段与增量边界见[五个连续里程碑](../../../docs/milestones.md)。真实身份、事件取消、持久队列和运行接口要求见[毕业集成演练](../integrations/README.md)，两者共用下面同一份交付清单与验收矩阵。

1. 接入你自己的新知识资料和一个只读业务工具，增加无证据与越权案例。
2. 将规划夹具替换为阶段08的真实模型适配器，保留动作Schema和服务端权限检查；无Key时仍可离线运行。
3. 增加取消、审批过期和参数修改后的重新审批；验证重复请求、重启与幂等键冲突。
4. 交付需求、架构决策、测试评估、部署、回滚与恢复说明，比较单Agent与多Agent成本。

## 提交

提交可独立启动的项目目录和环境说明；需求及成功标准；架构/数据流与接口契约；知识来源和工具Schema；身份、权限、审批、幂等与恢复设计；固定评估集与回归测试；部署、回滚、备份恢复和故障定位手册；新增需求实现与变更说明。附真实运行命令/输出、失败修复记录和关键执行轨迹。`practice.py`可以作为一个练习入口，但不能替代完整系统。

先按业务场景填写质量、延迟和成本阈值，再执行验收；报告必须包含实际测量结果、环境/版本和采样方法。若没有真实模型或服务环境，明确写“集成待验收”，不得以离线夹具结果代替。

| 验收场景 | 需要提交的证据 |
| --- | --- |
| 正常成功 | 请求、轨迹、最终业务状态及引用/工具结果 |
| 无证据 | 资料缺失时拒答或说明限制；展示检索结果 |
| 越权 | 未授权的知识、工单或写操作被服务端拒绝 |
| 审批过期、撤销、参数修改 | 旧审批不能执行；参数修改后重新审批的状态和审计记录 |
| 重放、幂等冲突、重启 | 同请求重放不重复生效；同键不同参数拒绝；重启恢复任务状态 |
| 故障定位 | 从请求关联ID定位模型/检索/工具失败，显示脱敏后的诊断信息 |
| 部署、回滚、恢复 | 干净环境启动、健康检查、回滚和恢复步骤的实际记录 |
| 未练过的新需求 | 新需求、设计取舍、实现、回归及旧行为保持证据 |

## 验收

独立扩展新需求；通过越权、过期、撤销、冲突、重放与重启案例；展示质量、延迟与成本的约定门槛及验证结果。不能将教学夹具的通过率写成真实模型评估结果。

完成后查看 [参考答案](../solutions/solution.py)，不要预先复制。
