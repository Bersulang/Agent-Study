# 阶段 52 独立练习

1. 增加两条任务，恢复后检查条数和状态，演练备份缺失与损坏。
2. 把相同反馈去重，保留来源标识但不保存敏感正文。
3. 写一份事故手册：发现、止损、恢复、核查、根因、回归。

## 提交

提交练习代码；自动校验命令会保存运行结果。设计原因可在验收对话中说明。

## 验收

实际恢复后读取数据而不是只看文件大小；解释RPO与RTO；说明反馈为什么先进入候选而非自动发布。

完成后查看 [参考答案](../solutions/solution.py)，不要预先复制。

## 自动校验接口

实现`solve(data)`，必填布尔值`backup_valid`及`tasks`列表（每项含`state`）；`feedback`可选，默认空列表，每项含`id`、`source`和敏感`body`。备份无效时返回`restored: false`、零`task_count`、空`states`和空`feedback`。备份有效时按任务列表生成状态计数，保留任务总数；反馈按`id`去重并保留`id`、`source`，不输出正文。该子集仅报告输入快照，不执行真实备份恢复，后者仍需集成演练。

自动校验只验证上述可重复的行为子集；涉及真实模型、服务、身份、部署或需要设计解释的部分，仍按本课集成任务独立验收。校验日志由统一命令自动保存，不要求手工粘贴命令输出。

从项目根目录运行：`.\.venv\Scripts\python.exe tools/check_exercise.py 52`。
