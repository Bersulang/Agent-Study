# 恢复与反馈练习参考

`solution.py`验证两条任务的数量和状态，并覆盖缺失备份、损坏备份和缺失源数据库。恢复只允许新目标文件，不直接覆盖已有库。

反馈通过category+case_id去重，状态固定pending_review；正文、身份与Token没有保存到候选列表。真实评估题需要脱敏及人工确认之后再存储。

## 事故手册参考

1. **发现**：就绪失败、任务积压或错误率告警，记录时间、版本与受影响任务类别。
2. **止损**：暂停写入和新任务，保留已执行副作用的结果，不盲目重试。
3. **选择备份**：按RPO确定可接受的数据时点，检查备份权限与完整性。
4. **隔离恢复**：恢复到新的数据库位置，验证Schema、行数、任务状态和关键约束。
5. **查证副作用**：对于数据库之外的业务系统，核对幂等键和真实操作结果；不能仅从任务状态推断。
6. **恢复流量**：受控切换，先小范围验证，再逐步恢复；记下实际RTO。
7. **根因与回归**：复盘触发条件和防护缺口，新增测试，改进告警与演练。

本课只在临时库演练，生产切换和覆盖操作不包含在脚本内。SQL格式完整不代表数据业务完整，必须检查必要表结构与实际查询。
