# 阶段26知识卡：按需加载的能力包

关联：[讲义](README.md)、[演示](examples/demo.py)、[练习](exercises/README.md)。

## 能力包

- 定义：把触发条件、步骤与资源组织在一起。
- 场景例子：工单报告包包含模板和统计脚本。
- 判断方法：观察输入、输出和失败分支，不能只看是否打印成功。
- 复习问题：去掉这一机制会导致什么错误？
- 演示关联：examples/demo.py的核心处理函数与tests/test_behavior.py。

## 发现

- 定义：读取摘要判断何时使用。
- 场景例子：只读取名称和用途列表。
- 判断方法：观察输入、输出和失败分支，不能只看是否打印成功。
- 复习问题：去掉这一机制会导致什么错误？
- 演示关联：examples/demo.py的核心处理函数与tests/test_behavior.py。

## 按需加载

- 定义：命中任务后再读取详细说明。
- 场景例子：不把所有说明塞进上下文。
- 判断方法：观察输入、输出和失败分支，不能只看是否打印成功。
- 复习问题：去掉这一机制会导致什么错误？
- 演示关联：examples/demo.py的核心处理函数与tests/test_behavior.py。

## 实现与真实系统的差别

### Agent Skills文件规范

- SKILL.md需要YAML frontmatter中的name与description；name与父目录名称一致。
- 自定义版本放metadata.version，不把顶层version当作规范内置字段。
- scripts放处理代码，资源按需读取；宿主支持的权限字段并不替代业务服务授权。
- 关联：resources/report/SKILL.md、template.md和scripts/summarize.py。

SKILL.md格式依赖宿主实现；本例是能力包机制演示，不是任何具体产品的完整加载器，也不执行不可信脚本。

## 调试方法

1. 缩小到一个输入，写出预期结果。
2. 跟踪本课trace或状态字段。
3. 检查错误发生在输入、控制还是输出边界。
4. 补失败案例并复跑测试。

## 验收关联

练习要求：为报告包编写实际SKILL.md，添加正例、负例、只读权限和版本；实现版本不匹配时拒绝加载，不能静默升级。

能定义、修改、排错和验证才构成掌握，课程交付不是学员通过。
