# 阶段 53 独立练习

1. 增加过期资料，检索员必须按active状态过滤。
2. 给报告中的每个事实列出来源，构造缺来源和矛盾资料。
3. 同一证据来自两个重复文档时，按来源ID去重并保持稳定输出。

## 提交

提交练习代码；自动校验命令会保存运行结果。设计原因可在验收对话中说明。

## 验收

提交研究任务、证据表、冲突案例和最终报告；解释事实、来源和推断区别；证明不会无限研究。

完成后查看 [参考答案](../solutions/solution.py)，不要预先复制。

## 自动校验接口

实现`solve(data)`，`facts`必填且为列表，每项含`text`和`source`，`active`可选且默认`false`。只保留active为真的事实；来源必须是非空字符串，否则抛`ValueError`。按首次出现的source稳定去重，返回`{"facts": [{"text": ..., "source": ...}]}`。本子集检查引用保留、过期过滤和重复来源，不判断研究报告的事实推理质量。

自动校验只验证上述可重复的行为子集；涉及真实模型、服务、身份、部署或需要设计解释的部分，仍按本课集成任务独立验收。校验日志由统一命令自动保存，不要求手工粘贴命令输出。

从项目根目录运行：`.\.venv\Scripts\python.exe tools/check_exercise.py 53`。

### 开放表达与固定契约

事实可附加置信度或说明字段；原始text、source、有效性过滤与去重仍需正确。
