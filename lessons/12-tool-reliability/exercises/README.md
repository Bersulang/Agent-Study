# 阶段12独立练习

完成课程演示后，关闭参考答案，修改 `practice.py` 中的 `solve(data)`。
练习与演示共享概念，但新增行为由你实现。

## 业务需求

实现solve(data)：data为重复创建请求列表，每条含key/title；返回唯一工单列表。同键同参数返回原结果，同键不同参数拒绝。允许不同键相同title创建两张；不能把标题当幂等键。

## 工作顺序

1. 写出输入、输出、拒绝条件和状态变化。
2. 先列成功、边界、失败三类案例及预期。
3. 实现后从项目根目录执行 `python lessons/12-tool-reliability/exercises/practice.py`。
4. 加入调用solve的代码，展示案例结果；当前骨架只报告待实现状态。
5. 解释每个分支为何存在，并保留原始输入以检查是否意外修改。

## 验收

- 独立完成新增业务行为；运行命令与输出由自动校验保存。
- 至少一个正常案例、一个空/缺失案例、一个失败案例。
- 能指出异常或拒绝发生在哪一层，不能把失败打印成成功。
- 能现场改变一个输入并预测结果，然后实际验证。
- 完成后才阅读 [参考答案](../solutions/solution.py)，说明与你实现的差别。

材料运行通过不代表学员能力通过；验收由实际讲解与修改证据决定。


## 自动练习校验

从项目根目录运行：`.\.venv\Scripts\python.exe tools/check_exercise.py 12`。校验日志自动保存，无需手工粘贴命令输出。自动检查未覆盖的真实集成仍需按本课项目标准验收。
